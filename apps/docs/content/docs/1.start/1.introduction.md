GitHub tools (`@github-tools/sdk`) is a TypeScript SDK that turns GitHub's API into 97 tools an AI agent can call: read a pull request, label an issue, rerun a workflow, open a release. Each tool has a typed input the model can fill, returns only the fields the model needs, and asks a person before it changes anything.

```ts [review.ts]
import { createGithubTools } from '@github-tools/sdk'
import { generateText, stepCountIs } from 'ai'

const { text } = await generateText({
  model: 'anthropic/claude-opus-5.5',
  tools: createGithubTools({ preset: 'code-review' }),
  stopWhen: stepCountIs(10),
  prompt: 'Summarize the open pull requests on vercel/ai and flag the risky ones.',
})
```

The `code-review` preset hands the model the 28 tools that review needs instead of all 97. If the model decides to post a review, the call stops and waits for your approval.

## What's in it

| Part | What it does |
| --- | --- |
| [Tools](/tools) | 97 GitHub operations as AI SDK tools, with shaped output and paging |
| [Presets](/presets) | Named tool sets for one job, such as `code-review` or `ci-ops` |
| [Approval](/approval) | Every write waits for a person, unless you say otherwise or let a model decide |
| [Auth](/auth) | A token from the environment, a GitHub App, or Vercel Connect |
| [Context](/context) | A default repository and pull request, so the model stops asking for them |
| [Commits](/commits) | Who the commits are from, and who co-authored them |
| [Errors](/errors) | Error codes the model can read and act on |

## Where it runs

The tools work in any [AI SDK](/integrations/ai-sdk) call. For a whole agent, mount the [eve extension](/integrations/eve) in one file. [TanStack AI](/integrations/tanstack-ai), [Vercel Workflow](/integrations/workflow) and [Chat SDK](/integrations/chat-sdk) each have their own entry point. [Integrations](/integrations) compares them.

## What it is not

GitHub tools doesn't run a server or hold state. It calls the GitHub API with the token you give it, from your own process. The [GitHub MCP server](https://github.com/github/github-mcp-server) gives a client the whole API over MCP; GitHub tools gives your code a typed subset, with approval decided in your code.
