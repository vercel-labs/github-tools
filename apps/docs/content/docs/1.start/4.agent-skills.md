`github-tools-agents` is an [Agent Skill](https://agentskills.io), published by this site, that teaches a coding assistant such as Cursor or Claude Code how to add `@github-tools/sdk` to a project. It covers tools and presets, `createGithubAgent`, the eve extension, durable agents with Vercel Workflow, tokens and approval. It loads the matching reference file only when a task needs it.

## Install it

```bash [Terminal]
npx skills add https://github-tools.com
```

Assistants that support Agent Skills discover it from the same origin. To try the skill from a Vercel preview deployment, pass that preview's URL instead, so the CLI reads the preview's catalog.

## What it contains

| File | Covers |
| --- | --- |
| `SKILL.md` | When to use the SDK, install, and the main integration patterns |
| `references/eve-extension.md` | Mounting `@github-tools/eve-extension` |
| `references/eve-agents.md` | The deprecated `@github-tools/sdk/eve` import |
| `references/durable-workflows.md` | `createDurableGithubAgent` with Vercel Workflow |
| `references/tokens-and-approval.md` | Tokens, Vercel Connect and `requireApproval` |
| `references/existing-project-integration.md` | Adding the tools to an app that already uses the AI SDK |

The catalog is at [`/.well-known/skills/index.json`](/.well-known/skills/index.json), and the sources are in [`apps/docs/skills/github-tools-agents`](https://github.com/vercel-labs/github-tools/tree/main/apps/docs/skills/github-tools-agents).
