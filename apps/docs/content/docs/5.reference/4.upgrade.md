`@github-tools/sdk/eve` and `@github-tools/sdk/connect/eve` register the tools from `agent/tools/`. Both are deprecated in favor of `@github-tools/eve-extension`, which mounts the same tools from `agent/extensions/` and adds Vercel Connect, `actAs`, `approvers` and the `'auto'` modes. The old imports keep working; new options land only in the extension.

## 1. Install the extension

:::code-group
```bash [pnpm]
pnpm add @github-tools/eve-extension
```
```bash [npm]
npm install @github-tools/eve-extension
```
```bash [yarn]
yarn add @github-tools/eve-extension
```
```bash [bun]
bun add @github-tools/eve-extension
```
:::

The extension brings its own `@github-tools/sdk`, so remove the direct dependency if nothing else in the agent imports it. Keep `eve`, and `@vercel/connect` if you use a connector.

## 2. Replace the tools file

Delete `agent/tools/github.ts` and create `agent/extensions/github.ts` with the same options.

Before:

```ts [agent/tools/github.ts]
import { createGithubTools } from '@github-tools/sdk/eve'

export default createGithubTools({
  preset: 'code-review',
  requireApproval: { createIssue: 'once' },
})
```

After:

```ts [agent/extensions/github.ts]
import githubExtension from '@github-tools/eve-extension'

export default githubExtension({
  preset: 'code-review',
  requireApproval: { createIssue: 'once' },
})
```

With Vercel Connect, the connector moves into the options:

```ts [agent/tools/github.ts]
import { connectGithubTools } from '@github-tools/sdk/connect/eve'

export default connectGithubTools('github/my-connector', { preset: 'maintainer' })
```

```ts [agent/extensions/github.ts]
import githubExtension from '@github-tools/eve-extension'

export default githubExtension({ connector: 'github/my-connector', preset: 'maintainer' })
```

Also remove `build.externalDependencies: ['@vercel/connect']` from `agent/agent.ts` if you added it for the direct import. The extension ships pre-built and doesn't need it.

## 3. Update tool names

The extension prefixes each tool with the mount file's name: `agent/extensions/github.ts` exposes `github__listPullRequests` where the direct import exposed `listPullRequests`. Update any code that matches tool names as strings, such as hooks, channel handlers or evals. Keys in `requireApproval`, `include`, `exclude` and `overrides` stay bare.

## Option mapping

| Direct import | Extension |
| --- | --- |
| `createGithubTools(options)` in `agent/tools/` | `githubExtension(options)` in `agent/extensions/` |
| `connectGithubTools(connector, options)` | `githubExtension({ connector, ...options })` |
| `connect`, static or `(call) => params` | `connect`, static or `(ctx, call) => params`, where `ctx` is the eve tool context |
| A factory per file, such as `listPullRequests()` in `agent/tools/list_pull_requests.ts` | One mount with `include: ['listPullRequests', ...]` |
| `token`, `preset`, `include`, `exclude`, `context`, `overrides`, `author`, `committer`, `coAuthors` | Unchanged |
| `requireApproval`: `true`, `false`, `'always'`, `'once'`, `'never'`, predicates | Unchanged, plus `'auto'` |
| | New: `actAs`, `approvers`, `preset: 'auto'`, `evaluation`, `overrides.<tool>.actAs` |

[eve](/integrations/eve) documents each option. `@github-tools/sdk/eve-runtime` is not deprecated: it holds the primitives the extension is built from, listed in the [API reference](/reference/api#github-toolssdkeve-runtime).
