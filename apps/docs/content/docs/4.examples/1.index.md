Each example is a whole agent for one job: its files, its [preset](/presets), its approval policy and how to run it. Two of them are runnable projects in the repository's [`examples/`](https://github.com/vercel-labs/github-tools/tree/main/examples) folder; the others live on their page.

| Example | Integration | What it does | Source |
| --- | --- | --- | --- |
| [Stale issue triager](/examples/eve-stale-issue-triager) | [eve](/integrations/eve) | Asks for updates on inactive issues and closes the unanswered ones once approved | On the page |
| [Release notes generator](/examples/ai-sdk-release-notes-generator) | [AI SDK](/integrations/ai-sdk) | Drafts release notes from what changed since the last release | On the page |
| [CI failure bot](/examples/vercel-workflow-ci-failure-bot) | [Vercel Workflow](/integrations/workflow) | Explains why a GitHub Actions run failed, in a durable chat | On the page |
| [Issue triage bot](/examples/chat-sdk-issue-triage-bot) | [Chat SDK](/integrations/chat-sdk) | Classifies, labels and comments on an issue when mentioned | Built on [`examples/pr-review-agent`](https://github.com/vercel-labs/github-tools/tree/main/examples/pr-review-agent) |
| [Manager agent with subagents](/examples/manager-agent-with-subagents) | [eve](/integrations/eve) | Routes requests to a reviewer, a triager and a releaser | On the page |
| PR review agent | [Chat SDK](/integrations/chat-sdk), [Vercel Workflow](/integrations/workflow) | Reviews a pull request when mentioned and answers follow-ups | [`examples/pr-review-agent`](https://github.com/vercel-labs/github-tools/tree/main/examples/pr-review-agent) |
| GitHub eve agent | [eve](/integrations/eve) | Code review and light maintenance with `preset: 'auto'` and `requireApproval: 'auto'`, reachable over HTTP and GitHub mentions | [`examples/eve`](https://github.com/vercel-labs/github-tools/tree/main/examples/eve) |

## Production templates

[Software Factory](https://github.com/vercel-labs/eve-software-factory-template) ([deploy](https://vercel.com/templates/eve/eve-software-factory)) takes work from GitHub and Linear through a classifier, an analyst, an implementer and a reviewer, and ends with a reviewed draft pull request for a person to merge. [Incident Response](https://github.com/vercel-labs/eve-sre-agent-template) ([deploy](https://vercel.com/templates/eve/eve-incident-response-agent)) investigates production alerts with live Datadog, GitHub and Vercel data, read-only by default. Both are eve agents that mount `@github-tools/eve-extension` with a Vercel Connect connector.
