Ask the agent to sweep a repository and it finds open issues with no activity in 30 days, comments to ask the author whether they still apply, and labels them `stale`. On the next sweep, it proposes closing the `stale` issues that got no answer, and each close waits for your approval.

## Files

```text
agent/
├── agent.ts               # defineAgent({ model: 'anthropic/claude-opus-5.5' })
├── instructions.md        # the sweep
└── extensions/
    └── github.ts          # the GitHub tools
```

The extension mounts the `issue-triage` [preset](/presets) and lets the two reversible writes run without asking:

```ts [agent/extensions/github.ts]
import githubExtension from '@github-tools/eve-extension'

export default githubExtension({
  connector: 'github/my-connector',
  preset: 'issue-triage',
  requireApproval: {
    addIssueComment: false,
    addLabels: false,
  },
})
```

`closeIssue` isn't listed, so it keeps the default and asks every time. Tools reach the model as `github__searchIssues`, `github__closeIssue` and so on, after the file name.

```md [agent/instructions.md]
You maintain this repository's issue tracker. Your only job is sweeping stale issues.

When asked to sweep a repository:
- Find open issues with no activity in the last 30 days with searchIssues,
  using `repo:<owner>/<repo> is:issue is:open updated:<YYYY-MM-DD` for the date 30 days ago.
- For each one without the `stale` label: post one comment asking the author whether
  it still applies, then add the `stale` label.
- For each one that already has the `stale` label and no comment from the author since:
  close it with a short, polite explanation.
- Never touch an issue that changed in the last 30 days.
- End with a short summary: commented, closed, skipped.
```

## Install

:::code-group
```bash [pnpm]
pnpm add @github-tools/eve-extension @vercel/connect eve ai zod
```
```bash [npm]
npm install @github-tools/eve-extension @vercel/connect eve ai zod
```
```bash [yarn]
yarn add @github-tools/eve-extension @vercel/connect eve ai zod
```
```bash [bun]
bun add @github-tools/eve-extension @vercel/connect eve ai zod
```
:::

eve needs `ai` 7. Create a connector named `github/my-connector` and pull its token as [Auth](/auth#create-a-github-connector) describes, or replace `connector` with `token: process.env.GITHUB_TOKEN`.

## Run it

```bash [Terminal]
npx eve dev
```

Ask "sweep stale issues on my-org/my-repo". The agent comments on and labels the inactive issues without stopping, then returns an approval request for each `closeIssue` call.

## Go further

To sweep on a cron, add an [eve schedule](https://eve.dev/docs/schedules) under `agent/schedules/`. A markdown schedule has no channel, so a write that asks for approval fails the session instead of waiting. Have the scheduled prompt only comment and label, and run the closing sweep from a chat where someone can approve.
