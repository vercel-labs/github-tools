Credit the GitHub App on pull requests and commits that run with a person's token.

With `actAs: 'user'`, or `'caller'` and a signed-in user, GitHub records the person as the author of what the agent writes. The extension now credits the App by default:

- `createPullRequest` ends the body with `Generated by [<app>](https://github.com/apps/<app>).`
- `createOrUpdateFile`, `editFiles`, `mergePullRequest` and `enablePullRequestAutoMerge` add the App's bot account to `coAuthors`, as `Co-authored-by: <app>[bot] <id+<app>[bot]@users.noreply.github.com>`.

The App is read from the person's token, so the connector must be backed by a GitHub App. Calls that run as the App add nothing. Turn it off or pick one credit with `attribution`:

```ts
export default githubExtension({
  connector: 'github/my-connector',
  actAs: 'caller',
  attribution: false, // or { footer: true, coAuthor: false }
})
```

`@github-tools/sdk/eve-runtime` exports the pieces: `githubAppBot(token)` reads the App behind a user token, `githubAppBotIdentity(bot)` returns its commit identity, `withGithubAppFooter(body, bot)` adds the footer, and `GITHUB_COMMIT_TOOLS` lists the tools that take `coAuthors`. A user token that GitHub lists no installation to fails with `github_tools.APP_BOT_UNKNOWN`.
