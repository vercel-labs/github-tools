The default decision model for `requireApproval: 'auto'` and `preset: 'auto'` is now `typesafe-ai/jev-1.14.0`, the latest Jev release, pinned instead of the moving `typesafe-ai/jev` alias. A new Jev release no longer changes how often the agent asks for approval until the SDK moves to it. Set `evaluation.model: 'typesafe-ai/jev'` to follow the latest release. The TanStack AI integration keeps `vercelGatewayDecider('typesafe-ai/jev')`, because `@tanstack/ai-vercel-gateway` 0.3 only accepts that model ID.
